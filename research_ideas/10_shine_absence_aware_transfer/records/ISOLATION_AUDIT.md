# Isolation

All copied model/training packages and new implementation are in this idea/code. Imports are recorded by each fold in IMPORT_AUDIT_*.json. Vendor preserves upstream source and license. Original GMR code/checkpoints/features are not modified. Inner annotations and loader sidecars are local. New edit features, checkpoints, predictions, logs and summaries are under this idea. Existing plan.md deletion predates this task and is untouched.

Outer split metadata is read for filtering; formal U annotation/feature/evaluation is not read. Upstream train JSONL is matched only to inner-train sources. User assumptions replace the earlier proposed absence/hierarchy review gates.
