# Semantic-novelty GMR: execution log index

Updated: 2026-10-04. This index records what was run, what was not run, the observed result, and the reason for each decision. All Novel-dev results are exploratory; the official U split was not accessed. A negative video label means the queried event is absent, not that the video contains no event.

The experiments used isolated copies/configurations under each direction. Original baseline sources, shared data, and pre-existing results were treated as read-only. The persistent queue validated the checkpoint, evaluation coverage, and expected artifacts before marking a task successful. Raw train/eval and repair logs are retained under each direction's `runs/` and `records/repairs/` directories. Aggregate metrics and full per-fold reported metrics are in the linked result records. Checkpoints, predictions, feature/data copies, and three very large machine-specific per-file manifests remain local and are not included in this documentation upload.
