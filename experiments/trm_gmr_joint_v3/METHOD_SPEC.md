# Moment-DETR-TRM-GMR-Joint-v3: Semantic-Group Robust AUC

Joint-v3 is an exploratory follow-up motivated by inspected Joint-v1 and Joint-v2 unseen results. These five U evaluations are not untouched unseen evaluations. U is excluded from training, semantic sampling/group selection, reference localization floors, checkpoint selection, calibration, and hyperparameter choices. All five splits share one frozen architecture and configuration.

The final existence score is the semantic branch's `logsumexp(candidate_evidence) - log(Q)`. The Moment-DETR localization branch, phrase matcher, candidate attention, gated refinement, TRM losses, empty-GT negative handling, and BCE remain inherited from Joint-v1 / Joint-v2's identical semantic path. PCA, visual fusion, and alpha are absent in v3. Models initialize from scratch; no v1/v2 checkpoint weights are loaded.

Frozen released annotations define `action = semantic_graph.action_base` and `composition = (action_base, object_concept or object)`, with `<no_object>` for an explicitly absent object. The released object concept is used directly without a new parser. Semantic IDs are supervision metadata, never model inputs.

For each level, within-group positive-negative pairs produce `L_g = mean(softplus(1 - s_pos + s_neg))`. The robust surrogate is `0.1 * logsumexp(L_g / 0.1)` over groups containing both labels, without subtracting log(group count). `loss_robust_auc = 0.5 * L_action + 0.5 * L_composition`. Missing-class groups are skipped; no valid groups give a graph-safe zero. This is a differentiable ranking surrogate, not exact AUROC differentiation and not an implementation of DRAUC or GroupDRO's published optimizer.

Batches alternate action and composition grouping. Every batch has four distinct semantic groups, each with two positives and two negatives (16 total). One pair in each group prefers an identical normalized query, then canonical composition; the second pair samples the wider group. Sampling is deterministic at seed `3407 + epoch`; replacement occurs only when a selected label bucket has fewer than two examples. An epoch has `ceil(number of Seen train rows / 16)` batches. Only groups containing both labels can enter the balanced sampler. The per-split semantic manifests record covered rows, excluded unpaired rows, and every group count. Alternating the two levels preserves more train coverage than sampling only paired compositions.

`loss_same_semantic` averages per-positive ranking losses, choosing available negatives in this priority: identical normalized query, identical composition, identical action. Pair counts at each priority are logged. The total loss retains inherited localization / label / TRM coefficients and adds `1.0 * BCE + 1.0 * loss_robust_auc + 1.0 * loss_same_semantic`. Margin is 1.0; robust temperature is 0.1. There is no global AUC term or hyperparameter sweep.

Checkpoint selection maximizes the minimum AUROC across a fixed Seen-validation action/composition group list. Groups must have at least five examples per label in Seen validation and both labels in Seen training; unsupported/sparse groups remain in diagnostic reports and are excluded from selection. The localization floor is the split's Joint-v1 best Seen-validation MR-full-mAP minus 1 percentage point. The reference comes exclusively from `best_*_val_preds_metrics.json`, never U metrics. Ties in worst AUROC prefer higher Seen MR-full-mAP, then the earlier epoch. If no checkpoint satisfies the floor, the split records `localization_constraint_failed` and does not run U inference.

Maximum epochs remain 100. The user's previous early stopping instruction is retained: stop after 30 consecutive epochs without Seen-val MR-full-mAP improvement. Early stopping and checkpoint selection are distinct: selection uses constrained worst-group AUROC, while patience tracks mAP. Other hyperparameters are inherited: seed 3407, lr 1e-4, wd 1e-4, lr_drop 400, batch/eval batch 16, clip length 1, max video length 200. The model does not use U for stopping or any other training decision.

After training, the selected checkpoint's threshold is frozen by Seen-only maximum balanced accuracy. Only then are full test annotations and matched U pairs read. Predictions retain full-precision existence logits/probabilities, candidate semantic evidence, phrase support/gates, margins, raw spans/scores, and official soft gating; the hard gate is diagnostic. Canonical AUROC and matched PairAcc use logits. Probability AUROC is checked against logit AUROC. Outputs include group AUROCs, localization, refusal/rejection, baseline comparisons, completion counts, and macros over eligible completed splits with the denominator stated.

Run `scripts/prepare_semantic_groups_joint_v3.py`, `scripts/smoke_test_trm_gmr_joint_v3.py`, and freeze the code and manifests before starting `scripts/run_joint_v3_multisplit.sh`. The GPU queues are GPU0: A1 → A3 → C2_alt; GPU1: A2_alt → C1. Each job automatically trains, calibrates, evaluates, and writes status; the final runner aggregates all five outcomes. Logs are in `results/moment_detr_trm_gmr_joint_v3/<split>/job.log` and `experiments/trm_gmr_joint_v3/queue.log`.

Background sources supplied in the design discussion: [DRAUC](https://proceedings.neurips.cc/paper_files/paper/2023/hash/8c086821724b99f4c756648bb0f165db-Abstract-Conference.html) studies distributionally robust AUC; [GroupDRO](https://github.com/kohpangwei/group_DRO) studies predefined-group worst-risk training. This experiment adapts conditional group ranking to the released video semantic annotations and makes no claim to reproduce those methods or guarantee improved unseen ranking.
