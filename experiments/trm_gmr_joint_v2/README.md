# Moment-DETR-TRM-GMR-Joint-v2

Joint-v2 is an exploratory follow-up motivated by Joint-v1 failure modes. Joint-v1 U results were already inspected and motivated this design; the five Joint-v2 U splits therefore are **not** an untouched unseen evaluation. Within this run, U is excluded from training, PCA fitting, checkpoint selection, threshold calibration, and hyperparameter selection. The five-split architecture and settings are frozen before U inference.

The model keeps the Joint-v1 localization, phrase-slot matcher, candidate-conditioned phrase attention, gated phrase refinement, semantic existence head, smooth logsumexp pooling, TRM losses, S+/S− training, Seen validation MR-full-mAP checkpoint selection, Seen-only balanced-accuracy threshold, official soft gate, and diagnostic hard gate. It adds (1) ViM-inspired query-independent visual evidence from a per-split background-PCA residual and (2) a batch-local pairwise AUC ranking surrogate. “ViM-inspired” describes the residual construction; this is not a reproduction of ViM. The PCA residual is generic visual evidence and does not mean that a U− video contains no event.

The raw visual input is the dataset's preprocessed feature sequence: SlowFast followed by CLIP visual features, each modality L2-normalized per clip by the existing dataset loader. The final two TEF dimensions are excluded. The current configured dimensions are 2304 + 512 = 2816, verified from the feature arrays by the PCA fitting job. PCA is fitted independently for each split from train S+ clip features outside GT windows only, seed 3407, at most 100,000 deterministic background vectors, rank `min(256, D-1)`. No S−, validation, test, query, phrase, prediction, or other split data enter PCA fitting.

For each detached predicted span, candidate visual features are masked-mean pooled from that raw sequence. The PCA-subspace residual norm is standardized using the train-background residual distribution and transformed with `tanh`. The final candidate evidence is `q_sem + softplus(alpha_raw) * visual_support.detach()`, initialized with alpha approximately 1.0. A semantic-only logit is retained for diagnosis. The residual branch cannot carry query information and cannot backpropagate into span coordinates.

The objective retains BCE for absolute binary supervision and adds `loss_auc_pairwise`, a differentiable pairwise AUC surrogate: `mean(softplus(1 - (s_pos - s_neg)))` over positive-negative pairs in the current batch, with `lambda_auc=0.5`. This is **not** exact AUROC and is not direct differentiation of AUROC. Batches without both labels contribute a graph-safe zero. DataLoader sampling remains shuffled batches of 16 without a balanced sampler.

All five splits run 100 epochs. Checkpoint selection remains Seen validation MR-full-mAP. The final checkpoint's threshold is selected from Seen validation S+/S− by maximum balanced accuracy. Canonical AUROC uses full-precision serialized logits; probability AUROC is checked against it. Candidate evidence and existence values are saved at Python float precision.

Run `scripts/smoke_test_trm_gmr_joint_v2.py`, then `scripts/run_joint_v2_multisplit.sh`. Per-split PCA, training, Seen-only calibration, and test inference are one atomic split job. Results and the final macro table are written below `results/moment_detr_trm_gmr_joint_v2/` and `MULTI_SPLIT_RESULT.md`.
